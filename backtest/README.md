# -0.25 平/半假强历史回测

这是独立回测模块，不会导入或修改现有 fingerprint.py，也不会发送微信消息。

## 固定规则

必须条件：主流公司初盘为主队 -0.25，且至少有4家有效欧赔、3家有效亚盘。

六项评分：

1. 初始主胜中位数 2.00 至 2.20
2. 初始客胜中位数 2.55 至 3.10
3. 客队 +0.25 初始水位不高于 0.90
4. 临场未形成主让 -0.5 或更深共识
5. 至少20%的公司从 -0.5 退到 -0.25
6. 主胜中位数没有较初赔下降超过 0.08

## GitHub Actions 运行

在 Actions 页面选择 Backtest -0.25 fake favourite：

- 留空 match_ids：自动抓最近 days 天完场比赛。
- 填 match_ids：只校验指定ID。
- scores 可按 2908783=1-1,2908774=0-0 填写。

每次运行会生成 backtest-025-results 工件，包含 CSV、Markdown 报告和运行元数据。


## 回测顺序

先用两个已知样本做解析校验，再用两天数据校准历史日期和完场比分，最后运行30天全量回测。正式报告以30天及后续更长区间为准，小样本结果不用于宣称模型命中率。
