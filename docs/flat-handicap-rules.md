# 平手盘6分类与自动评分（冻结版）

本规则只使用赛前初盘和即时盘，赛果仅在回测结算阶段读取。

| ID | 分类 | 硬条件 | 方向 |
|---|---|---|---|
| F1 | 原生均势 | 主流初盘0、即时0，未形成单边水位与欧赔压力 | 仅记录，不推送 |
| F2 | 主队暗强 | 0→0，主水优势/主胜下降/客胜上升至少2项 | 主队不败 |
| F3 | 客队暗强 | 0→0，客水优势/客胜下降/主胜上升至少2项 | 客队不败 |
| F4 | 升盘强化 | 0→一方让0.25或更深 | 最终取得让球权方 |
| F5 | 退盘削弱 | 一方让0.25或更深→0 | 原让球方的对手 |
| F6 | 穿零反转 | 初盘和即时盘的让球方相反 | 最终取得让球权方 |

## 100分评分

- 类别基础分：F1=20、F2/F3=35、F4=40、F5=45、F6=50。
- 有效公司不少于5家加10，不少于8家再加5。
- 初盘和即时共识度均不低于60%加6；不低于70%加10。
- 方向方即时水位不高于0.92加10。
- 方向方水位下降至少0.04加8。
- 方向方胜赔下降至少0.04加10。
- 对手胜赔上升至少0.03加7。
- 方向方即时胜赔比对手至少低0.08加5。
- 方向方高水不低于1.03扣10；公司共识不足60%扣8。
- F1封顶59分，只做基准样本。

## 回测去留标准

按时间顺序前70%训练、后30%留出验证。每类的60/70/80分阈值只能在训练集选择。

KEEP并进入实时微信通知必须同时满足：

1. 总样本不少于30，留出样本不少于12；
2. 训练ROI和留出ROI都大于0；
3. 全样本ROI不低于2%；
4. 留出集方向方不败率不低于60%。

WATCH继续积累、不通知；DROP停用。不能用少量样本的高命中替代这些标准。
